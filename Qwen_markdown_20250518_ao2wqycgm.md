# Gestion des Courriers - Projet Laravel + Mobile

Projet complet de gestion des courriers d'arrivée/départ avec :
- Formulaire d'enregistrement
- Directions / Sous-directions / Services
- Rôles utilisateurs (admin, chef service, agent)
- Notifications hiérarchiques
- Archivage automatique après 3 mois
- Calendrier de suivi
- Recherche full-text
- Vue PDF
- Application mobile React Native

## 🛠 Technologies utilisées

- Laravel 10
- PHP 8.2
- MySQL / PostgreSQL
- React Native (application mobile)
- Chart.js (dashboard)
- Laravel Scout (recherche full-text)
- DomPDF (génération PDF)
